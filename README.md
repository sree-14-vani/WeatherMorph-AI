# WeatherMorph AI

WeatherMorph AI is a Gradio-based image transformation application.

## Features

- Winter effect
- Rain and fog effects
- Summer, spring, and autumn effects
- Day-to-night and night-to-day transformations
- Adjustable effect intensity
- Batch image processing and ZIP downloads

## Technologies

- Python
- Gradio
- OpenCV
- NumPy
- Pillow
